Integrasi Google Sheets

Langkah-langkah koneksi ke Google Sheets:

1. Buat Google Sheet baru dengan 5 Sheet: Members, Products, Transactions, Banners, Settings

2. Buka Extensions → Apps Script, tempel kode dari file gs.js → Deploy → New deployment (Type: Web app, Execute as: Me, Who has access: Anyone)

3. Salin URL Deployment Apps Script ke kolom di bawah ini

4. Klik Hubungkan. Data akan otomatis sync 2 arah.
